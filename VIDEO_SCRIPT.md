0:00–0:20 — Introduce FlytBase Command Centre and the two accounts. Explain that the dashboard reads the Questathon MCP server-side and never exposes the token.

0:20–0:55 — Open Eastern Counties Police Alliance. Show the five manager questions. Explain that deal values, stakeholder authority, and deadlines must come from source records, not a champion's unsupported claim.

0:55–1:30 — Open Aldermoor Industrial Group. Show how verified insurance savings are separated from projected savings. Point out source references and the unknowns that still need Finance or Insurance confirmation.

1:30–2:05 — Open the raw source response panel. Show that the CRM preserves the MCP payload for auditability and does not invent IDs.

2:05–2:35 — Demonstrate the next-step note box and explain that it calls `write_note` through a server route. Do not show the token or environment settings.

2:35–3:00 — Explain what remains: schema-specific mapping, persistent signal ingestion, ranked dated actions, and full source-linked financial calculations. Close with the Monday actions the manager can authorize.
